# 语法与专项微课

本目录不建立一套与学校平行的完整语法课程，而用于维护七年级英语的 **语法同步学习 + 结构强化 + 错误追踪 + 迁移应用**。

## 核心原则

1. 学校教材决定主要语法进度。
2. 新概念英语 1 / 2 用于句型结构和语法强化。
3. Think Level 1 用于把语法迁移到真实听力、口语和写作中。
4. 作业、试卷、阅读、口语和作文中的真实错误决定是否需要专项微课。
5. 不以刷题数量判断掌握程度，而看能否理解、造句、口头使用和写作使用。

## 每周基本安排

- **周一/周二：学校语法同步 10–15 分钟**  
  理解规则 → 正反例 → 3–5 道控制练习 → 自己说 1 句 → 自己写 1 句。
- **周四：Think / 新概念语法迁移 5–10 分钟**  
  从本周材料中找真实例句，做替换、问答或短表达。
- **周六：错误复盘约 10 分钟**  
  判断是粗心、规则不懂、规则会但不会用，还是与其他结构混淆。

语法不要求每天单独训练；日常在听说读写中隐性复现。

## 四级掌握标准

每个语法点按四级记录：

- **L1 识别**：看到句子能识别结构。
- **L2 理解**：知道为什么这样使用，并能解释主要规则。
- **L3 控制使用**：给提示能正确造句、改写或完成练习。
- **L4 主动使用**：能在口语或写作中主动调用。

原则：达到 L3 才算基础掌握；达到 L4 才算真正进入语言能力。

## 错误触发规则

- 偶然错误：当场订正。
- 同类错误再次出现：加入本周复习，补 3–5 个针对练习。
- 同类错误连续出现 2–3 次：建立 15–20 分钟专项微课。
- 同一规则在作文或口语中反复不会用：即使选择题正确，也需要迁移训练。

## 专项微课固定结构

**概念/规则 → 正反例 → 易错点 → 3–5 道练习 → 口头应用 → 写作应用 → 后续复测**
