# 学习计划

这里维护七年级英语学习的总体执行框架，不在本目录重复保存各能力模块的具体教材和训练细节。

## 当前文件

- `grade7_learning_system.md`：七年级总体目标、每日/每周结构、阶段检查、错误触发规则。
- `daily_checklist.md`：可直接打印或复制使用的每日 20–30 分钟打卡模板。
- `material_rules.md`：学校教材、新概念和新增专项教材的引入与退出规则。

## 拆分原则

总体计划回答“为什么学、每天/每周怎么安排、如何检查”。

具体模块回答“这一项能力具体怎么练、用什么教材”。因此教材和训练方法分别放在：

- `02_vocabulary/`
- `03_listening/`
- `04_speaking/`
- `05_reading/`
- `06_writing/`
- `07_grammar/`

这样新增或替换某一本教材时，只需要修改对应能力模块。

后续如果阶段计划确实复杂，再新增 `monthly_plan.md` 或阶段计划；当前不为了目录完整而提前拆更多文件。
