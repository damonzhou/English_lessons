## 打卡原则

1. 学校教材仍是第一优先级；Think Level 1 是长期听说写能力主线。
2. Think 课堂优先 Listening + Speaking；能通过听和说训练的内容，不优先变成抄写和长篇书面练习。
3. Think 不追求每天推进新课，一个主题可以连续训练多次。
4. 每个 Think Unit 固定包含 Pattern / Substitution Drill，不把句型替换当可选练习。
5. Pattern Drill 采用“结构不变、内容不断变化”的完整句输出，不机械重复同一句。
6. 当天高频替换之后必须安排 1–2 天、3–4 天和约 7 天后的延迟复现。
7. 当前口语支架顺序：跟读 → Pattern Drill → 扩句 → 提示表达 → 半开放表达 → 自由表达。
8. 不因口语暂时低于 A2 就完整降回 Think Starter；只有具体前置内容缺失时才局部回补。
9. 语法不要求每天单独刷题；每周重点做“学校同步 + 语境迁移 + 错误复盘”。
10. 语法达到 L3 才算基础掌握，达到 L4 才算真正进入口语/写作能力。
11. 阅读错题必须尽量找到原文依据和真实错因。
12. 每周至少有一次复盘，把重复错误转入专项训练。
