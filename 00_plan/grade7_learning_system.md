# 七年级英语学习体系

## 1. 总体目标

用七年级这一年完成从小学英语学习向初中英语能力学习的过渡，同时兼顾校内成绩和长期语言能力。

核心目标：
- 校内：学校教材核心词汇、词组、语法、课文扎实掌握。
- 词汇：从“认识”发展到“会读、会搭配、会造句、能调用”。
- 听力：从捕捉单词发展到听懂句子、对话、主要信息。
- 口语：从模仿逐步过渡到主动表达。
- 阅读：从逐句翻译过渡到理解上下文、定位证据、判断逻辑、概括主旨。
- 写作：逐步建立个人主题表达库。
- 长期：形成“输入 → 积累 → 使用 → 纠错 → 再使用”的增长循环。

## 2. 学习主线

优先级：

1. 学校教材：第一主线，保证校内学习与考试基础。
2. 新概念英语 1/2：补充语言输入、句型、听力与表达。
3. 能力专项教材：按需要引入，尤其是听力、口语、阅读与写作。
4. 临时练习册：作为训练材料和错误样本，不作为唯一课程主线。

原则：不建立一套与学校完全平行的综合英语课程，而建立可持续的能力训练系统。

## 3. 每日训练框架

建议每天 20–30 分钟；学校作业较重时可缩短到约 15 分钟，但尽量不中断。

- 词汇/词块：5–7 分钟
- 听力：约 5 分钟
- 口语：约 5 分钟
- 阅读或写作：8–10 分钟，隔天轮换
- 积累/纠错：2–3 分钟

数量不是硬指标，训练质量和连续性优先。

## 4. 每周结构

### 周一：教材输入
- 学校本周核心词汇/词组
- 听课文或对话
- 跟读
- 选 1–2 个可复用表达进入积累库

### 周二：词汇 + 口语
- 复习词汇
- 跟读短对话
- 句型替换
- 主动说 2–3 句

### 周三：阅读
- 1 篇适当难度阅读
- 先理解大意
- 每题寻找原文依据
- 分析错因
- 积累高价值表达

### 周四：听力 + 口语
- 盲听
- 对照文本
- 再听
- 跟读
- 提示式复述 2–5 句

### 周五：写作
- 60–80 词左右主题写作或仿写
- 使用本周 2–3 个积累表达
- 检查并修改

### 周六：综合复盘
- 词汇抽查
- 短听力
- 阅读或错题复盘
- 口语提示式表达
- 修改作文
- 判断是否出现重复性错误

### 周日：轻量巩固
- 快速复习本周重点
- 重听最难的一段音频
- 重读一篇文章/课文
- 用积累表达口头造句

## 5. 口语当前阶段

当前主要问题是“学过但主动调用困难”，因此不要求一开始自由表达 1 分钟。

训练顺序：
1. 跟读
2. 句型替换
3. 提示式表达
4. 自由表达

当前建议比例：40% / 30% / 20% / 10%。

阶段目标是先做到：把学过的简单句迅速、连续、正确地说出来。

## 6. 素材分级

- A 级：学校教材，必须掌握。
- B 级：新概念、专项教材、阅读和听力中高频且值得主动吸收的内容。
- C 级：偶遇生僻或明显超出当前阶段的内容，认识即可。

## 7. 错误触发规则

- 偶然错误：当场订正。
- 同类错误再次出现：加入本周复习，并补少量针对性练习。
- 同类错误连续出现 2–3 次：建立 15–20 分钟专项微课。
- 如果是阅读/作文方法问题：优先修改方法，不通过单纯增加题量解决。

## 8. 阶段检查

每 4 周检查一次：
- 词汇：认读 + 搭配 + 简单运用
- 听力：陌生度适中的短材料
- 口语：提示式表达，条件成熟再减少提示
- 阅读：正确率 + 原文定位 + 错因
- 写作：与 4 周前作品比较
- 积累迁移：检查积累是否真正进入口语和作文

## 9. 模块化原则

本文件只维护总体学习体系。

具体训练规则与教材在各模块独立维护：
- `02_vocabulary/`
- `03_listening/`
- `04_speaking/`
- `05_reading/`
- `06_writing/`
- `07_grammar/`

这样以后更换或新增教材时，不需要重写整个学习计划。
