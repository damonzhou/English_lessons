# 七年级英语学习体系

## 1. 总体目标

用七年级这一年完成从小学英语学习向初中英语能力学习的过渡，同时兼顾校内成绩和长期语言能力。

核心目标：
- 校内：学校教材核心词汇、词组、语法、课文扎实掌握。
- 词汇：从“认识”发展到“会读、会搭配、会造句、能调用”。
- 听力：从捕捉单词发展到听懂句子、对话、主要信息。
- 口语：从模仿逐步过渡到主动表达。
- 阅读：从逐句翻译过渡到理解上下文、定位证据、判断逻辑、概括主旨。
- 写作：从正确简单句发展到围绕熟悉主题完成连贯 A2 短文，并建立个人表达库。
- 语法：从“会做题”发展到“能解释、能造句、能在口语和写作中主动使用”。
- 长期：形成“输入 → 积累 → 使用 → 纠错 → 再使用”的增长循环。

## 2. 课程主线与教材分工

### 第一主线：学校教材
定位：A级内容，优先级最高。

负责：
- 校内词汇、词组和语法；
- 课文和学校听力；
- 学校作文题、作业、考试与课堂要求。

### 第二主线：Think Second Edition Level 1（A2）
定位：七年级长期 **听力 + 口语 + 写作能力主线**，同时提供青少年主题的阅读、词汇和语言输入。

重点使用：
- Listening；
- Speaking / Functions；
- Writing；
- 对话和音视频；
- 与主题相关的高频词块；
- 适量 Reading，作为听说写共同输入。

Think Writing 负责“教写作方法”，但原书题量不足以承担全年每周写作，因此在 `06_writing/writing_bank.md` 中围绕 12 个核心 Writing 扩展为约 36 个候选题，并在 `model_answer_bank.md` 维护原创 A2 范文。

不要求：
- 与学校教材完全同步；
- 为了“学完教材”而机械完成全部语法练习；
- 一开始就达到教材所有 A2 自由口语要求；
- 36 个扩展写作题全部完成。

当前口语能力可能低于综合 A2，因此 Think Level 1 的口语任务采用“降支架”方式：

**示范输入 → 跟读 → 句型替换 → 提示式表达 → 原教材口语任务**

必要时可借用 Think Starter 同主题内容局部回补，但不完整重学 Starter。

### 第三主线：新概念英语 1 / 2
定位：语言结构、句型、精读和复述补充。

负责：
- 基础句型自动化；
- 语法结构理解；
- 精听、跟读和复述；
- 给学校、Think 和写作提供可迁移表达。

新概念不与 Think 竞争听说写主线位置。

### 语法训练：跨模块能力线
语法不建立第四套平行教材，而采用：

**学校同步 → 新概念结构强化 → Think语境迁移 → 错误触发专项微课**

具体规则见 `07_grammar/grammar_training_plan.md`。

### 其他能力专项教材
阅读、写作、听力、口语可以按需要引入新的教材或素材，但必须服务于明确能力缺口，不因为“资料多”而增加并行主线。

### 临时练习册
作为训练材料和错误样本，不作为唯一课程主线。

## 3. 每日训练框架

建议每天 20–30 分钟；学校作业较重时可缩短到约 15 分钟，但尽量不中断。

- 学校词汇/词块：5–7 分钟
- 听力：约 5–8 分钟；Think 日优先使用 Think Level 1 音频
- 口语：约 5–8 分钟；Think 日直接承接当天听力输入
- 阅读或写作：8–10 分钟，隔天轮换；学校任务较重时可省略额外训练
- 积累/纠错：2–3 分钟
- 语法：不要求每天独立训练；每周安排 2 次显性训练，其余通过听说读写自然复现

原则：Think 的同一主题尽量形成 **听 → 说 → 读 → 写 → 再说** 的迁移；语法则嵌入这条链路，不拆成只会做题的独立模块。

## 4. 每周结构

### 周一：学校教材输入 + 语法同步
- 学校本周核心词汇/词组
- 听课文或对话
- 跟读
- 选 1–2 个可复用表达进入积累库
- 如本周有新语法：安排 10–15 分钟同步训练
  - 理解核心规则
  - 看正反例
  - 做 3–5 道针对题
  - 自己说 1–2 句
  - 自己写 1–2 句

### 周二：Think Level 1 听力 + 口语
- 首次盲听一个短片段
- 完成教材核心听力任务
- 对照文本确认没听出的地方
- 跟读 3–5 个关键句
- 选 1 个句型做替换
- 根据提示主动说 2–4 句

### 周三：阅读
- 1 篇适当难度阅读
- 先理解大意
- 每题寻找原文依据
- 分析错因
- 积累高价值表达

### 周四：Think Level 1 深化 + 语法迁移
- 继续本周同一主题，不急于换新单元
- 重听或学习新的短片段
- 做句型替换或角色对话
- 用关键词完成 3–5 句提示式表达
- 条件成熟时尝试教材原始 Speaking task
- 从 Think / 新概念 / 学校课文中找 2–3 个本周语法真实例句
- 用该结构完成替换、问答或短表达
- 为周五写作收集 2–3 个可迁移表达

### 周五：写作
优先顺序：
1. 学校真实作文；
2. 当前 Think Unit 原 Writing；
3. `06_writing/writing_bank.md` 对应扩展题。

执行：
- 先列 3–5 个要点；
- 前期以 60–80 词为主；
- 主动使用本周 2–3 个积累表达；
- 如果本周有重点语法，至少尝试正确使用 1–2 次；
- 完成第一稿和基础检查。

### 周六：新概念 + Think + 写作 + 语法错误复盘
- 新概念短课文/对话精读或跟读
- 复盘本周 Think 听力难点
- 修改周五作文，形成较完整版本
- 用作文关键词做一次简短口头复述
- 集中检查本周语法错误：粗心 / 规则不懂 / 会规则但不会用 / 相似结构混淆
- 同类错误连续出现 2–3 次时触发专项微课

### 周日：轻量巩固
- 快速复习本周重点
- 重听最难的一段音频
- 重读一篇文章/课文
- 用积累表达口头造句
- 如有专项微课，做一次间隔复测，而不是重新刷大量同类题

## 5. Think Level 1 当前执行标准

### 听力
首次听陌生片段时：
- 80% 以上基本能听懂：可快速通过，把重点放到口语；
- 约 60%–80%：最适合精听；
- 低于约 50%：缩短片段、降低任务复杂度，必要时局部回补。

### 口语
当前不要求一开始完成完整 A2 自由表达。

训练顺序：
1. 跟读
2. 句型替换
3. 提示式表达
4. 半开放对话
5. 自由表达

阶段目标：把学过的简单句迅速、连续、正确地说出来。

### 写作
固定流程：

**Input → Collect → Plan → Draft → Check → Rewrite → Speak**

前期标准：
- 60–80 词为主；
- 内容完整优先于高级表达；
- 简单句正确优先；
- 至少主动使用 2 个近期积累表达；
- 范文用于比较和修改，不用于整篇背诵。

完整规则见 `06_writing/writing_plan.md`。

### 单元推进
不以“每周必须学完一个 Unit”为指标。

一个 Think 主题可以连续训练多次，直到：
- 主要听力内容理解稳定；
- 3–5 个核心表达能够主动调用；
- 至少能完成提示式口语任务；
- 能完成一个与本主题匹配的基础写作或有效改写；
再进入下一主题。

## 6. 语法执行标准

### 四级掌握
- **L1 识别**：看到句子能识别结构。
- **L2 理解**：知道为什么这样使用。
- **L3 控制使用**：给提示能正确造句、改写和做题。
- **L4 主动使用**：口语或写作中能自然调用。

达到 L3 才算基础掌握；达到 L4 才算真正进入语言能力。

### 专项微课触发
- 偶然错误：当场订正；
- 同类错误再次出现：本周复习 + 3–5 个针对练习；
- 同类错误连续出现 2–3 次：15–20 分钟专项微课；
- 选择题会但口语/作文反复错：仍视为未达到 L4，需要迁移训练。

### 微课流程

**规则/概念 → 正反例 → 易错点 → 控制练习 → 口头应用 → 写作应用 → 间隔复测**

语法掌握进度维护在 `07_grammar/grammar_progress.md`。

## 7. 素材分级

- A 级：学校教材，必须掌握。
- B 级核心：Think Level 1 中用于听说写训练的核心表达和任务。
- B 级补充：新概念、阅读、其他专项教材中高频且值得主动吸收的内容。
- C 级：偶遇生僻或明显超出当前阶段的内容，认识即可。

## 8. 错误触发规则

- 偶然错误：当场订正。
- 同类错误再次出现：加入本周复习，并补少量针对性练习。
- 同类错误连续出现 2–3 次：建立 15–20 分钟专项微课。
- 如果是阅读/作文方法问题：优先修改方法，不通过单纯增加题量解决。
- 如果 Think 口语反复卡在同一语言结构：先做句型替换和提示式表达，不直接要求自由输出。
- 如果写作内容总是写不出来：先加强 Plan；如果复杂句错误明显增多：主动降回可控表达。

## 9. 阶段检查

每 4 周检查一次：
- 学校词汇：认读 + 搭配 + 简单运用
- Think 听力：选择一个未提前学习的同级别短材料，检查主旨和细节
- Think 口语：熟悉主题提示式表达，条件成熟再减少提示
- 阅读：正确率 + 原文定位 + 错因
- 写作：比较第一稿和修改稿，并与 4 周前作品比较
- 语法：检查核心语法点当前处于 L1/L2/L3/L4 哪一级，并用新题、口语或作文证据确认
- 积累迁移：检查 Think / 学校 / 新概念表达是否真正进入口语和作文

如果连续两个阶段 Think Level 1 听力明显偏简单、口语能较稳定完成 A2 任务、写作也能稳定完成 A2 熟悉主题任务，再评估是否向更高一级过渡，而不是单看语法和阅读成绩。

## 10. 模块化原则

本文件只维护总体学习体系。

具体训练规则与教材在各模块独立维护：
- `02_vocabulary/`
- `03_listening/`
- `04_speaking/`
- `05_reading/`
- `06_writing/`
- `07_grammar/`
- `08_new_concept/`
- `11_think_level1/`

这样以后更换或新增教材时，不需要重写整个学习计划。
