# 教材与素材使用规则

## 1. 总原则

教材服务于训练目标，不因为拥有一本教材就要求完整学完。

选择新材料时优先判断：
1. 是否解决当前真实短板；
2. 难度是否匹配；
3. 是否有高质量音频/视频、文本和答案；
4. 是否可以形成“输入 → 模仿 → 使用 → 复盘”的闭环；
5. 是否与学校主线明显重复。

## 2. 当前教材层级

### 第一层：学校教材
必须掌握，是校内考试和日常学习的第一主线。

### 第二层：Think Second Edition Level 1（A2）
长期听力 + 口语主教材。

重点使用：
- Listening；
- Speaking / Functions；
- 对话与音视频；
- 青少年主题词块；
- 与听说主题相关的适量阅读。

当前口语能力可能在 A1 / A1+，因此允许使用低一级输出支架完成 A2 教材任务。

不因口语弱而完整降回 Starter；只有具体前置缺口时局部回补。

### 第三层：新概念英语 1 / 2
长期补充教材。

用途：
- 新概念1：短对话、基础句型、精听、跟读、替换表达和复述；
- 新概念2：后续选择性用于较长句、阅读、写作和复杂表达。

新概念不与 Think 同时承担“听说主教材”的角色。

### 第四层：能力专项教材与临时材料
仍可以新增，尤其适合：
- 阅读；
- 写作；
- 更真实的陌生听力；
- 特定口语短板。

但新增教材不能自动成为另一套完整主线。

## 3. 新教材引入条件

满足以下任一条件时可以新增教材：
- Think Level 1 无法提供足够的某类听力场景；
- 口语需要更细的发音、互动或表达专项训练；
- 阅读材料难度长期过低或过高；
- 作文题型或表达训练明显不足；
- 某项能力连续 4 周停滞；
- 需要更真实的说话人、语速或语境变化。

新增前先判断：问题是否可以通过调整现有 Think 任务解决。如果可以，不急于增加教材。

## 4. 不建议的做法

- 同时完整推进学校教材、Think、新概念和另一套综合教材。
- 为了完成 Think 的进度而机械做完所有练习。
- 每个模块都配置多本练习册并追求全部完成。
- 因为材料难就直接认定“更有效”。
- 只做选择题，不进行跟读、复述、改写或主动表达。
- 口语一遇到困难就整体降级教材。

## 5. 新材料试用机制

除已经确定为主线的学校教材和 Think Level 1 外，任何新教材先试用 2–4 周，再决定是否长期保留。

试用时记录：
- 难度；
- 完成时间；
- 错误类型；
- 是否增加主动表达；
- 是否能迁移到学校学习/阅读/作文；
- 是否提供了 Think 当前缺少的能力训练。

如果只是增加任务量而没有带来能力增益，则停止使用。

## 6. 当前素材体系

1. 学校教材：校内第一主线。
2. Think Level 1：长期听力 + 口语主线。
3. 新概念1/2：句型、语法、精读与复述补充。
4. 阅读练习册：阅读题型与错因训练。
5. 作文练习册/学校作文：写作任务入口。
6. 其他听说材料：只有出现明确需求时再增加。
