# 教材与素材使用规则

## 1. 总原则

教材服务于训练目标，不因为拥有一本教材就要求完整学完。

选择新材料时优先判断：
1. 是否解决当前真实短板；
2. 难度是否匹配；
3. 是否有高质量音频/视频、文本和答案；
4. 是否可以形成“输入 → 模仿 → 使用 → 复盘”的闭环；
5. 是否与学校主线明显重复。

## 2. 教材层级

### 第一层：学校教材
必须掌握，是校内考试和日常学习的第一主线。

### 第二层：长期辅助教材
目前主要包括《新概念英语》1 和 2。

用途：
- 新概念1：短对话、基础句型、听力、跟读、替换表达。
- 新概念2：选择性用于较长句、阅读和写作表达，不要求七年级完整推进。

### 第三层：能力专项教材
可以新增，尤其适合：
- 听力
- 口语
- 阅读
- 写作

专项教材不自动成为“第二套学校课程”。只抽取与当前目标匹配的部分。

## 3. 新教材引入条件

满足以下任一条件时可以新增教材：
- 现有材料无法提供足够的陌生听力；
- 口语缺少结构化场景和表达支架；
- 阅读材料难度长期过低或过高；
- 作文题型或表达训练明显不足；
- 某项能力连续 4 周停滞；
- 需要更明确的 CEFR 难度梯度。

## 4. 不建议的做法

- 同时完整推进学校教材、新概念和另一套综合教材。
- 每个模块都配置多本练习册并追求全部完成。
- 因为材料难就直接认定“更有效”。
- 只做选择题，不进行跟读、复述、改写或主动表达。

## 5. 试用机制

任何新教材先试用 2–4 周，再决定是否长期保留。

试用时记录：
- 难度
- 完成时间
- 错误类型
- 是否增加主动表达
- 是否能迁移到学校学习/阅读/作文

如果只是增加任务量而没有带来能力增益，则停止使用。

## 6. 当前优先补充方向

当前最值得引入新材料的是：
1. 听力：补充学校课文和新概念之外的陌生、分级、真实语境输入。
2. 口语：补充有句型支架、场景任务和渐进输出设计的材料。

具体候选见：
- `03_listening/materials.md`
- `04_speaking/materials.md`
