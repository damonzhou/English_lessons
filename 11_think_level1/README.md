# Think Second Edition Level 1（A2）课程模块

## 1. 课程定位

Think Level 1 是七年级阶段的长期 **听力 + 口语 + 写作能力主线**，并作为阅读、词汇和主题表达的综合输入来源。

当前不把它当作第三套完整语法课程。

教材分工：
- 学校教材：校内第一主线；
- Think Level 1：长期听说写能力主线；
- 新概念英语 1 / 2：句型、语法、精读、复述补充。

写作专项规则与扩展题库独立维护在 `06_writing/`，避免把 Think 原书当成全年唯一题库。

## 2. 当前起点

暂定能力画像：
- 综合理解：A2 倾向；
- 主动口语：A1 / A1+；
- 写作：以 A1+ → A2 过渡标准训练；
- 因此教材从 Think Level 1 开始，但口语任务采用降支架方式，写作前期以 60–80 词可控表达为主。

不完整学习 Think Starter。只有具体主题出现明显前置缺口时，才局部借用 Starter 回补。

## 3. 课堂时间优先级

Think 课堂的首要目标是增加 **可理解听力输入 + 高频口头输出**。

正常情况下，建议把约 **70%–80% 的课堂有效训练时间**用于：
- 教材 Audio / Video；
- 家长口头问题、指令和信息差任务；
- 跟读与语音模仿；
- Pattern / Substitution Drill；
- Sentence Expansion；
- 问答与角色扮演；
- Supported / Free Speaking。

书面练习主要承担：
- 快速检查理解；
- 记录真实错误；
- Writing 迁移；
- 课后巩固。

原则：**能在课堂上“听和说”解决的内容，不优先变成抄写和长篇书面练习。**

## 4. 每个 Think 主题的固定学习流程

### Step 1：Preview
- 看主题和图片；
- 预测场景；
- 预习少量影响理解的核心词。

### Step 2：Listening / Reading Input
- 首次尽量不看文本；
- 抓主旨和关键信息；
- 完成教材核心任务；
- 对照文本分析没听出/没读懂的地方；
- 再次确认。

### Step 3：Notice language
从听力、阅读、对话中选：
- 3–5 个值得理解的核心表达；
- 其中 2–4 个作为本主题主动句型/表达目标。

不把整页所有生词都加入积累库。

### Step 4：Imitate
- 跟读 3–5 个关键句；
- 模仿重音、节奏和停顿；
- 必要时分句训练。

### Step 5：Pattern / Substitution Drill（固定环节）
这是每个 Unit 的必做环节，不只用于 Welcome Unit。

对 2–4 个核心句型进行：
1. 单槽替换；
2. 多槽替换；
3. 主语/肯否/问句等必要变化；
4. 延迟复现。

第一次训练时，每个核心句型通常完成 **10–18 个不同的完整句输出**，不是机械重复同一句。

推荐节奏：
- 当天：高频替换；
- 1–2 天后：换素材再练；
- 3–4 天后：只给关键词/问题；
- 约 7 天后：在口语或 Writing 中再次调用。

完整标准见 `substitution_drill_standard.md`。

### Step 6：Sentence Expansion
在主干句稳定后逐步增加：
- when；
- where；
- who with；
- how often；
- why；
- how long。

训练目标是从简单句扩展为信息更完整的句子，再自然过渡到 2–3 句连续表达，而不是无限制造超长句。

### Step 7：Supported Speaking
根据完整框架 → 替换词 → 关键词 → 问题提示逐步撤掉支架，完成 3–5 句表达。

### Step 8：Original Speaking Task
当提示式表达比较稳定后，再尝试 Think 原教材的 Speaking task。

如果卡住，不直接给答案，而是重新增加一级支架或回到 Pattern Drill。

### Step 9：Writing Transfer
围绕当前 Unit 的 Writing：
- 先分析写作目的和结构；
- 从本周输入中选择 2–3 个可迁移表达；
- 列 3–5 个内容要点；
- 完成 60–80 词左右第一稿；
- 检查并修改；
- 条件允许时再用关键词口头复述。

如果 Think 原 Writing 当周不适合，也可以从 `06_writing/writing_bank.md` 选择对应 A/B/C 扩展题。

### Step 10：Delayed Reuse
一周后或下一相关主题中再次调用本 Unit 的核心句型。

真正进入长期能力的标准不是“当天会说”，而是隔几天仍能在新情境中调用。

## 5. 单次训练时长

Think 主训练建议每次约 20–30 分钟。

不要求一次完成全部流程，可以拆开。例如：

**第一次：Listening Input → Notice → Imitate → Pattern Drill**

**第二次：Listening Recall → Pattern Drill 复现 → Sentence Expansion → Supported Speaking**

**第三次：Role-play / Original Speaking → Writing Transfer → Delayed Reuse**

训练质量优先于教材推进速度。

## 6. 每周节奏

### 周二：新输入 + 第一轮句型自动化
- 新听力/阅读片段；
- 听懂主旨和细节；
- 跟读；
- 选 2–4 个核心句型；
- 每个核心句型进行单槽/多槽替换；
- 做一次短真实输出。

### 周四：间隔复现 + 扩句 + 口语
- 不先看原句，快速复现周二核心句型；
- 换新的替换素材；
- 做主语/肯否/问句等必要变化；
- 做句子扩展；
- 完成 3–5 句提示式表达；
- 条件成熟时尝试原 Speaking task。

### 周五：写作迁移
优先选择：
1. 学校真实作文；
2. Think 当前 Unit 原 Writing；
3. `06_writing/writing_bank.md` 同主题扩展题。

要求尽量主动使用本 Unit 已经 Drill 过的 1–3 个句型。

### 周六：延迟提取 + 听说复盘
- 不看模板复现核心句型；
- 用关键词做短口语；
- 加一个新的听力问答/角色扮演；
- 修改周五作文；
- 检查句型是否真正迁移；
- 记录仍需要高频 Drill 的句型。

### 下一周
在新主题、日常问答或写作中随机复现上周 1–2 个句型。

## 7. 一个主题什么时候可以结束

满足大部分以下条件即可进入下一主题：
- 主要听力内容能够理解；
- 熟悉问题/指令能较快做出口头反应；
- 核心词块理解稳定；
- 2–4 个核心句型经过替换训练后能迅速生成；
- 更换主语、时间、地点等后仍基本准确；
- 能根据提示连续说 3–5 句；
- 至少 1–2 个句型在延迟复现中仍能主动调用；
- 能完成一次简短问答或角色扮演；
- 能完成一个匹配当前能力的主题写作或有效改写；
- 没有明显需要立即补的基础知识缺口。

不要求所有练习 100% 完成。

## 8. 什么时候回补 Starter

只在以下情况局部回补：
- Level 1 某个基础句型完全不会；
- 同一主题基础词汇缺失明显；
- 已做充分替换训练仍不能生成基本句；
- 听力困难主要来自基础语言缺口，而非语音识别。

回补完成后立即返回 Level 1。

写作单独出现困难时，优先降低题目支架和字数，而不是因此整体退回 Starter。

## 9. 阶段评估

每 4 周检查：

### 听力
选一个未提前学习的 Think Level 1 同级别短材料：
- 主旨；
- 关键信息；
- 熟词能否听出来；
- 是否过度依赖文本；
- 听到熟悉问题/指令后是否能直接做出反应。

### 句型自动化
随机抽取近期核心句型：
- 给替换词能否迅速生成；
- 主语改变后是否稳定；
- 3–7 天后是否仍能调用；
- 是否需要中文翻译后才能说。

### 口语
选一个熟悉主题：
- 启动速度；
- 连续句数；
- 已学表达调用率；
- 停顿情况；
- 是否仍大量依赖中文翻译。

### 写作
选一个熟悉主题：
- 内容是否完整；
- 句子准确度；
- 基本连接；
- 是否主动使用积累表达；
- 第一稿到修改稿是否有明显改进。

### 迁移
检查本月 Think 表达是否进入：
- 学校作文；
- 日常口语；
- 阅读/写作积累库。

## 10. 升级 Think Level 2 的条件

不按学习时长自动升级。

只有在连续两个阶段中：
- Level 1 陌生听力大部分稳定；
- 高频核心句型能够较快自动调用；
- A2 熟悉主题口语任务能较稳定完成；
- A2 熟悉主题写作能较稳定完成；
- 提示依赖明显下降；
- Level 1 大部分核心任务已缺乏足够挑战；

才开始做 Think Level 2 试学与重新定级。

## 11. Unit 文件建议

正式学习每个 Unit 时，建议至少记录：

```text
unitXX/
├── notes.md
├── listening.md
├── pattern_drills.md
├── speaking.md
└── writing.md
```

其中 `pattern_drills.md` 保存：
- 2–4 个核心句型；
- 替换槽位素材；
- Day 1 / Day 2 / 延迟复现结果；
- 是否已经进入 Active 状态。

`listening.md` 不只记录答案，还记录：
- 首次听懂比例；
- 熟词听不出的地方；
- 可用于口头反应的指令/问题；
- 可直接转成 Speaking 的句型。

只有真正开始对应 Unit 时再创建。
