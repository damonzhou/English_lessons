# Think Second Edition Level 1（A2）课程模块

## 1. 课程定位

Think Level 1 是七年级阶段的长期 **听力 + 口语主教材**，并作为阅读、词汇和写作的主题输入来源。

当前不把它当作第三套完整语法课程。

教材分工：
- 学校教材：校内第一主线；
- Think Level 1：长期听说主线；
- 新概念英语 1 / 2：句型、语法、精读、复述补充。

## 2. 当前起点

暂定能力画像：
- 综合理解：A2 倾向；
- 主动口语：A1 / A1+；
- 因此教材从 Think Level 1 开始，但口语任务采用降支架方式完成。

不完整学习 Think Starter。只有具体主题出现明显前置缺口时，才局部借用 Starter 回补。

## 3. 每个 Think 主题的学习流程

### Step 1：Preview
- 看主题和图片；
- 预测场景；
- 预习少量影响理解的核心词。

### Step 2：Listening
- 首次盲听；
- 抓主旨和关键信息；
- 完成教材核心任务；
- 对照文本分析没听出的地方；
- 再听确认。

### Step 3：Notice language
从听力/对话中选：
- 3–5 个值得理解的核心表达；
- 其中 2–3 个作为本周主动表达目标。

不把整页所有生词都加入积累库。

### Step 4：Imitate
- 跟读 3–5 个关键句；
- 模仿重音、节奏和停顿；
- 必要时分句训练。

### Step 5：Substitute
围绕核心句型替换：
- 人物；
- 时间；
- 地点；
- 动作；
- 原因；
- 个人真实信息。

每个核心句型做 2–3 组即可。

### Step 6：Supported speaking
根据关键词、句型框架或问题提示，说 3–5 句。

当前这是口语训练的核心阶段。

### Step 7：Original speaking task
当提示式表达比较稳定后，再尝试 Think 原教材的 Speaking task。

如果卡住，不直接给答案，而是重新增加一级支架。

### Step 8：Transfer
本主题至少选 1–2 个表达用于：
- 学校作文；
- 日常口语；
- 新概念复述；
- 下一次同主题表达。

## 4. 单次训练时长

Think 主训练建议每次约 10–15 分钟。

一次不必完成整个页面或 Unit，可以只完成：

**盲听 → 对照 → 跟读 → 1个句型替换 → 2–3句表达**

训练质量优先于教材推进速度。

## 5. 每周节奏

### 周二：新输入
- 新听力片段；
- 听懂主旨和细节；
- 跟读；
- 句型替换；
- 2–4 句提示式表达。

### 周四：同主题深化
- 重听或第二段材料；
- 角色对话；
- 提示式表达 3–5 句；
- 条件成熟时尝试原 Speaking task。

### 周六：迁移复盘
- 重听本周最难片段；
- 不看文本说出本周核心表达；
- 用 3–5 个表达进行短复述；
- 记录需要继续训练的问题。

## 6. 一个主题什么时候可以结束

满足大部分以下条件即可进入下一主题：
- 主要听力内容能够理解；
- 核心词块理解稳定；
- 2–3 个表达能够主动调用；
- 能根据提示连续说 3–5 句；
- 能进行一次简短问答；
- 没有明显需要立即补的基础知识缺口。

不要求所有练习 100% 完成。

## 7. 什么时候回补 Starter

只在以下情况局部回补：
- Level 1 某个基础句型完全不会；
- 同一主题基础词汇缺失明显；
- 提示已经降到很低仍无法组织基本句；
- 听力困难主要来自基础语言缺口，而非语音识别。

回补完成后立即返回 Level 1。

## 8. 阶段评估

每 4 周检查：

### 听力
选一个未提前学习的 Think Level 1 同级别短材料：
- 主旨；
- 关键信息；
- 熟词能否听出来；
- 是否过度依赖文本。

### 口语
选一个熟悉主题：
- 启动速度；
- 连续句数；
- 已学表达调用率；
- 停顿情况；
- 是否仍大量依赖中文翻译。

### 迁移
检查本月 Think 表达是否进入：
- 学校作文；
- 日常口语；
- 阅读/写作积累库。

## 9. 升级 Think Level 2 的条件

不按学习时长自动升级。

只有在连续两个阶段中：
- Level 1 陌生听力大部分稳定；
- A2 熟悉主题口语任务能较稳定完成；
- 提示依赖明显下降；
- Level 1 大部分核心任务已缺乏足够挑战；

才开始做 Think Level 2 试学与重新定级。
