# Think Level 1 家长备课模板

> 每次备课控制在 10–20 分钟。一次课只抓少量目标，不追求把整页做完。
>
> 课堂优先训练 Listening + Speaking。正常情况下，约 70%–80% 的有效训练时间用于听、跟读、替换、扩句、问答和角色扮演。

## 10. 课堂听说量检查

- [ ] 至少 5–10 个可理解 Listening 小片段 / 指令 / 问题
- [ ] 跟读 3–5 个关键句
- [ ] 2–4 个核心句型进入 Drill
- [ ] 每个核心句型产生足够的完整口头变式
- [ ] 至少 5–10 个真实问答回合
- [ ] 至少 1 个角色扮演或信息差任务
- [ ] 至少 1 次完整 Exit Task

如果准确率明显下降，不为了凑数量继续加新内容。

## 11. Exit Task

> ____________________________________
