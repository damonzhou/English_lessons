# Think Level 1 — Welcome Unit 家长教学计划

## 1. 定位

Welcome Unit 主要用于：

1. 快速复习进入 Level 1 前需要的 A1 基础；
2. 诊断“认识/会做题”与“能主动说”之间的差距；
3. 建立 Think 的学习方法：听 → 模仿 → 替换 → 主动表达。

由于当前判断是“综合理解接近 A2、主动口语可能 A1/A1+”，Welcome Unit **不建议像普通 Unit 一样慢速完整讲解**。

建议：
- 明显会的内容快速通过；
- 语法题会做但口语调用慢的内容重点训练；
- 不会的基础点记录到 `07_grammar/grammar_progress.md`；
- Welcome 完成后尽快进入 Unit 1。

预计：**4–6 次，每次 15–25 分钟**。

---

## 2. 官方内容骨架

### A — All About Me
重点：
- personal information
- countries / nationalities
- `be`
- names / addresses / phone information

核心输出目标：
- 能介绍自己；
- 能问姓名、年龄、来自哪里；
- 能介绍另一个人；
- 能听懂基础姓名、数字、地址类信息。

### B — What's That?
重点：
- classroom objects
- prepositions of place
- classroom language
- object pronouns
- `this / that / these / those`

核心输出目标：
- 能描述常见物品在哪里；
- 遇到听不懂/不会拼写时能用英语求助；
- 能在真实句子中使用基本宾格代词和指示代词。

### C — About Time
重点：
- days / months / dates
- ordinal numbers
- telling the time
- daily routine

核心输出目标：
- 能说生日和日期；
- 能听懂常见时间；
- 能用时间顺序介绍自己的普通一天。

### D — My Things
重点：
- possessions
- `have got`
- `I like` vs `I'd like`
- food / simple choice situations

核心输出目标：
- 能谈自己有什么/没有什么；
- 能问别人是否拥有某物；
- 能区别“喜欢”与“想要”；
- 能完成简单点餐/选择对话。

## 3. 建议教学节奏

### Lesson W1 — All About Me

目标：
- `I'm ... / My name's ...`
- `Where are you from?`
- `I'm from ...`
- `How old are you?`
- `This is my friend ...`

Exit Task：

> 假设第一次见一个新同学，完成 30–45 秒自我介绍 + 2 个问答。

如果 `am/is/are` 准确但说得慢，重点做替换，不重新系统讲 `be`。

---

### Lesson W2 — Classroom Survival English

目标：
- 课堂物品与位置；
- 用英语处理“没听懂、不会说、不会拼”的情况。

主动表达优先：
- `Excuse me.`
- `Can you say that again, please?`
- `Sorry, I don't understand.`
- `What does ... mean?`
- `How do you spell ...?`
- `How do you say ... in English?`

Exit Task：

> 家长故意说一个孩子没听清/不知道的词，让孩子不用中文，使用英语求助。

这部分即使内容简单也建议认真练，因为它是以后自学 Think 的“工具语言”。

---

### Lesson W3 — Where Is It?

目标：
- `in / on / under / behind / in front of / between`
- `this / that / these / those`
- object pronouns 的基础使用

Exit Task：

> 看真实房间或书桌，连续描述 4–6 个物品的位置，并完成 2–3 个指认问答。

如果书面题正确但口语说位置慢，则重点做真实物品练习。

---

### Lesson W4 — Dates, Time and My Day

目标：
- days / months / ordinal numbers；
- birthday / date；
- telling the time；
- daily routine。

Exit Task：

> 不看书介绍自己一个普通上学日，至少包含 5 个动作和 4 个时间点。

---

### Lesson W5 — My Things

目标：
- `I've got ...`
- `I haven't got ...`
- `Have you got ...?`
- `Yes, I have. / No, I haven't.`

Exit Task：

> 介绍自己拥有的 4–6 件物品，再问家长 3 个 `Have you got ...?` 问题。

---

### Lesson W6 — I like / I'd like

目标：
- `I like ...` = 一般喜好；
- `I'd like ...` = 当前想要/请求；
- 简单食物选择与点餐。

Exit Task：

> 完成一个 1 分钟以内的 lunch / picnic role-play。

如果区别非常稳定，可以和 W5 合并。

---

## 4. Welcome Unit 快速通过标准

一个模块满足以下条件即可继续，不需要刷完全部扩展练习：

- 教材基础题约 80%–90% 能独立完成；
- 核心句型不需要翻译即可理解；
- 给提示时能迅速造句；
- 熟悉话题能说 3–5 句；
- 没有反复出现的基础语法错误。

### 如果出现三种情况

#### 情况 A：题很简单，口语也很顺
快速通过。

#### 情况 B：题很简单，但说不出来
不要降教材级别；做 `practice_templates.md` 中的替换与撤支架训练。

#### 情况 C：题本身就频繁出错
记录具体知识缺口，必要时回补 Starter 对应内容或建立语法微课。

## 5. Welcome Unit 最重要的诊断结果

完成后至少记录：

- `be`：L1 / L2 / L3 / L4
- 方位介词：L1 / L2 / L3 / L4
- object pronouns：L1 / L2 / L3 / L4
- `this/that/these/those`：L1 / L2 / L3 / L4
- 日期时间：L1 / L2 / L3 / L4
- daily routine：L1 / L2 / L3 / L4
- `have got`：L1 / L2 / L3 / L4
- `I like / I'd like`：L1 / L2 / L3 / L4

其中：
- L1 = 能识别；
- L2 = 能解释；
- L3 = 给提示能正确使用；
- L4 = 真实口语/写作能主动调用。

对她目前最值得观察的是：**有多少内容已经 L2/L3，但还没到 L4。**

## 6. 简单句扩展训练

Welcome Unit 新增 `sentence_expansion_templates.md`，用于把已经会说的基础短句逐层扩展。

推荐扩展维度：

**基础句 → 时间 → 地点 → 人物 → 频率 → 原因 / 方式 → 2–3 句连贯表达**

例如：

> I play badminton.
>
> I usually play badminton after school with my friends because it's fun.

但训练目标不是把所有信息塞进一个超长句。必要时应自然拆开：

> I usually play badminton after school with my friends. We often play for about an hour because it's fun.

Welcome 阶段重点看三点：
- 扩展后主干语法是否仍正确；
- 能否根据 `when / where / who with / how often / why` 自主补充信息；
- 能否从一个短句过渡到 2–3 句连续表达。

详细模板和练习卡见 `sentence_expansion_templates.md`。
