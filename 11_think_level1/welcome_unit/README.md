# Think Level 1 — Welcome Unit 家长教学计划

## 1. 定位

Welcome Unit 主要用于：

1. 快速复习进入 Level 1 前需要的 A1 基础；
2. 诊断“认识/会做题”与“能主动说”之间的差距；
3. 建立 Think 的学习方法：听 → 模仿 → 替换 → 扩句 → 主动表达。

由于当前判断是“综合理解接近 A2、主动口语可能 A1/A1+”，Welcome Unit **不建议像普通 Unit 一样慢速完整讲解**。

建议：
- 明显会的内容快速通过；
- 语法题会做但口语调用慢的内容重点训练；
- 不会的基础点记录到 `07_grammar/grammar_progress.md`；
- Welcome 完成后尽快进入 Unit 1。

预计：**4–6 次，每次 20–30 分钟**。

### 课堂时间原则

Welcome Unit 的课堂目标优先是 **Listening + Speaking**。

正常情况下，约 **70%–80% 的有效训练时间**用于：
- 听教材音频 / 家长口头指令；
- 跟读、模仿；
- Pattern / Substitution Drill；
- Sentence Expansion；
- 问答；
- 角色扮演；
- 提示式 / 自由表达。

书面练习用于快速确认理解、记录错误和课后巩固，不让选择题和抄写占据课堂主体。

## 2. 官方内容骨架

### A — All About Me
重点：
- personal information
- countries / nationalities
- `be`
- names / addresses / phone information

核心输出目标：
- 能介绍自己；
- 能问姓名、年龄、来自哪里；
- 能介绍另一个人；
- 能听懂基础姓名、数字、地址类信息。

### B — What's That?
重点：
- classroom objects
- prepositions of place
- classroom language
- object pronouns
- `this / that / these / those`

核心输出目标：
- 能描述常见物品在哪里；
- 遇到听不懂/不会拼写时能用英语求助；
- 能在真实句子中使用基本宾格代词和指示代词。

### C — About Time
重点：
- days / months / dates
- ordinal numbers
- telling the time
- daily routine

核心输出目标：
- 能说生日和日期；
- 能听懂常见时间；
- 能用时间顺序介绍自己的普通一天。

### D — My Things
重点：
- possessions
- `have got`
- `I like` vs `I'd like`
- food / simple choice situations

核心输出目标：
- 能谈自己有什么/没有什么；
- 能问别人是否拥有某物；
- 能区别“喜欢”与“想要”；
- 能完成简单点餐/选择对话。

## 3. 建议教学节奏

### Lesson W1 — All About Me
目标：个人信息、`be`、自我介绍和介绍别人。

Exit Task：假设第一次见一个新同学，完成 30–45 秒自我介绍 + 2 个问答。

### Lesson W2 — Classroom Survival English
目标：课堂物品与位置；用英语处理“没听懂、不会说、不会拼”的情况。

主动表达优先：
- `Excuse me.`
- `Can you say that again, please?`
- `Sorry, I don't understand.`
- `What does ... mean?`
- `How do you spell ...?`
- `How do you say ... in English?`

Exit Task：家长制造没听清/不知道的词，孩子不用中文，使用英语解决。

### Lesson W3 — Where Is It?
目标：方位介词、`this / that / these / those`、object pronouns。

Exit Task：看真实房间或书桌，连续描述 4–6 个物品的位置，并完成听指令摆放任务。

### Lesson W4 — Dates, Time and My Day
目标：日期、时间、daily routine、频率表达。

Exit Task：不看书介绍普通上学日，至少 6 句、4 个时间点，并听懂若干时间/动作提示。

### Lesson W5 — My Things
目标：`have got / has got` 的肯定、否定和问答。

Exit Task：介绍自己拥有/没有的物品，再和家长完成信息问答。

### Lesson W6 — I like / I'd like
目标：一般喜好 vs 当前想要；简单食物选择与点餐。

Exit Task：完成 45–60 秒 lunch / picnic role-play。

## 4. 固定训练链

每节课按需要从以下链路执行：

**Listening Input → Imitate → Pattern Drill → Sentence Expansion → Supported Speaking → Real-use Task → Delayed Recall**

### Listening Input
- 第一遍尽量不看文本；
- 先抓主旨/任务；
- 第二遍抓关键信息；
- 对照后再听确认。

### Pattern Drill
每个核心句型：
- 跟读 2–3 次；
- 单槽替换 6–10 次；
- 多槽替换 3–5 次；
- 做必要的主语/肯否/疑问变化；
- 最后进入真实问答。

### Sentence Expansion
从正确主干开始，按需增加：
- when
- where
- who with
- how often
- why
- how long

### Speaking 撤支架
完整句型 → 替换词 → 关键词 → 问题 → 场景 → 自由表达。

## 6. Welcome Unit 快速通过标准

一个模块满足以下条件即可继续，不需要刷完全部扩展练习：
- 教材基础题约 80%–90% 能独立完成；
- 核心句型不需要翻译即可理解；
- 听到熟悉问题/指令能较快反应；
- 给关键词能迅速造完整句；
- 熟悉话题能连续说 3–5 句；
- 没有反复出现的基础语法错误。

### 情况 A：题简单，听说也顺
快速通过。

### 情况 B：题简单，但说不出来
不降教材级别，重点做高频替换、扩句、延迟提取和真实问答。

### 情况 C：题本身频繁出错
记录具体知识缺口，必要时回补 Starter 对应内容或建立语法微课。

## 7. 诊断记录

完成后至少记录：
- `be`：L1 / L2 / L3 / L4
- 方位介词：L1 / L2 / L3 / L4
- object pronouns：L1 / L2 / L3 / L4
- `this/that/these/those`：L1 / L2 / L3 / L4
- 日期时间：L1 / L2 / L3 / L4
- daily routine：L1 / L2 / L3 / L4
- `have got`：L1 / L2 / L3 / L4
- `I like / I'd like`：L1 / L2 / L3 / L4

其中：
- L1 = 能识别；
- L2 = 能解释；
- L3 = 给提示能正确使用；
- L4 = 真实口语/写作能主动调用。

对当前阶段尤其关注：**有多少内容已达到 L2/L3，但听到问题时反应慢或还不能主动说到 L4。**
