# 听力教材与素材路线

## 1. 当前主素材

### 学校教材音频
定位：A级材料，必须掌握。

目标：
- 课内内容听懂而不是只会看懂；
- 建立声音与词汇、句型的对应；
- 为学校听力和口语打基础。

### Think Second Edition Level 1（A2）
定位：七年级长期听力主教材。

重点使用：
- Listening；
- 对话与音视频；
- 与 Speaking / Functions 连动的输入材料；
- 主题相关的核心词块。

固定流程：
1. 首次盲听：先抓人物、场景、主题和主要信息；
2. 完成教材主旨/细节任务；
3. 对照文本：定位熟词听不出、连读弱读、生词或长句问题；
4. 再听确认；
5. 跟读 3–5 个关键句；
6. 把其中至少 1 个句型转入口语输出。

使用原则：
- 每周建议 2 次主训练，每次约 10–15 分钟；
- 周末再做 1 次 5–10 分钟复盘；
- 不要求一次学完整个 Unit；
- 一个主题可以重复多次，直到听力理解和口语调用都比较稳定；
- 如果材料首次盲听明显低于 50%，先缩短片段或降低任务复杂度，不机械硬听。

### 新概念英语 1 音频
定位：B级补充素材。

适合：
- 短对话精听；
- 跟读；
- 句型识别；
- 简短复述。

新概念2可在后续选择性加入，不以整册推进为目标。

## 2. 为什么 Think 成为长期主听力教材

学校教材和新概念仍然保留，但它们存在以下限制：
- 学习后文本熟悉，容易把“记住内容”误认为“真正听懂”；
- 陌生语境和说话人变化相对有限；
- 听力和主动口语的连续任务不足。

Think Level 1 提供相对稳定的 A2 青少年主题输入，并能直接接到 Speaking，因此更适合作为长期听说主线。

## 3. 其他教材与素材的定位

### Cambridge Prepare Second Edition
状态：候选补充，不与 Think 同时作为主线。

只有在以下情况考虑引入：
- Think 的听力风格长期不适合；
- 需要更多陌生 A2 听力；
- 有明确的剑桥考试训练需求。

### Wider World / BBC 类真实素材
状态：后续真实听力补充。

当 Think Level 1 的 A2 材料稳定后，可少量加入不同说话人、真实视频和更自然语速，避免只适应单一教材录音。

### 数字专项资源
只用于增加听力次数和陌生材料，不替代主教材。

## 4. 每周建议

七年级当前阶段：
- 学校教材音频：随学校进度；
- Think Level 1：2 次主训练；
- Think 复盘：1 次；
- 新概念：1 次精听/跟读，可与新概念课程合并；
- 其他陌生听力：暂不强制，Think 本身先承担主要陌生输入。

## 5. 难度判断

一段新的 Think 材料首次盲听后：
- 能理解约 80% 以上：偏简单，可快速通过，把重点转到口语输出；
- 能理解约 60%–80%：最适合精听；
- 低于约 50%：通常过难，应缩短材料、减少任务或局部回补。

判断“听懂”时不能只看题做对没有，还要区分：
- 真正听懂；
- 根据关键词猜对；
- 因为提前看过文本而记住内容。

## 6. 听力训练记录

每次只记录：
- Think Unit / 主题 / 材料来源；
- 首次听懂程度；
- 1–3 个没听出来的关键点；
- 原因：生词 / 熟词听不出 / 连读弱读 / 句子太长 / 注意力；
- 3–5 个需要跟读的关键句；
- 哪个表达需要进入当天口语训练。
