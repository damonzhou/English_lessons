# 听力教材与素材路线

## 1. 当前主素材

### 学校教材音频
定位：A级材料。

目标：
- 课内内容听懂而不是只会看懂；
- 建立声音与词汇、句型的对应；
- 为学校听力和口语打基础。

### 新概念英语 1 音频
定位：B级长期素材。

适合：
- 短对话精听；
- 跟读；
- 句型识别；
- 简短复述。

新概念2可在后续选择性加入，不以整册推进为目标。

## 2. 为什么需要增加新的听力材料

学校教材和新概念的主要问题不是质量不足，而是：
- 学习后文本熟悉，容易把“记住内容”误认为“真正听懂”；
- 陌生语境输入不足；
- 语速、说话人和场景变化有限。

因此七年级听力应该逐渐加入“陌生但可理解”的分级材料。

## 3. 候选教材

### Cambridge Prepare Second Edition（优先候选）

定位：中学生综合英语教材，可主要抽取 Listening / Speaking / Video / Skills 部分使用。

建议从 A2 级别评估，不直接根据年龄选级别。

适合原因：
- 面向 Secondary 学习者；
- 主题更贴近青少年；
- 每单元包含听说读写训练；
- 有配套音频和数字资源；
- 可以作为学校教材之外的陌生听力来源。

使用方式：
- 不完整同步学整册；
- 每周选 1–2 段听力；
- 以“盲听 → 任务 → 对照文本 → 再听 → 跟读/复述”为主。

当前状态：候选，建议先试用 2–4 周。

### Cambridge Think Second Edition（备选）

定位：中学生综合课程，A2 起有明确的 Listening、Reading、Writing 等技能模块。

适合在以下情况下考虑：
- Prepare 的内容风格不合适；
- 希望听力和阅读、写作形成更强的主题联动。

同样不建议与学校教材完整并行。

### Cambridge Personalised Learning A2 Reading, Listening & Speaking（数字专项候选）

定位：A2 Secondary 数字专项训练。

特点：
- 阅读、听力为分级短任务；
- 包含口语练习；
- 适合作为碎片化补充而非主教材。

如果以后希望引入数字化自适应训练，可以单独评估。

## 4. 每周建议

七年级前期：
- 学校 / 新概念熟悉材料精听：2–3 次
- 陌生分级听力：1–2 次

每次 5–10 分钟即可。

## 5. 难度判断

一段新材料首次盲听后：
- 能理解约 80% 以上：偏简单，可用于泛听或口语模仿；
- 能理解约 60%–80%：最适合精听；
- 低于约 50%：通常过难，应降级或缩短材料。

不以“生词越多越好”为标准。

## 6. 听力训练记录

每次只记录：
- 材料来源；
- 首次听懂程度；
- 1–3 个没听出来的关键点；
- 原因：生词 / 熟词听不出 / 连读弱读 / 句子太长 / 注意力；
- 是否需要进入口语跟读。
