# 第一次怎么练

L001是系统演示课，不替换Think主线。已经准备了当日学校或Think音频时，可按材料模板替换，并据实际录音与原文重写问题答案；不能套用L001答案。

## 开始之前，家长准备

打开L001官方音频页面，先确认音频可播放且与页面原文一致。展开原文用于家长核对后再收起，并确保孩子看不到答案。

按[私有数据说明](../PRIVATE_DATA.md)复制模板到本地private目录，打开新的每日记录。由家长向ChatGPT发送：

> 按项目指令备课L001。以下是材料卡。不要评估听力等级，也不要在孩子开始前展示原文和答案。后面由我播放音频并转达她的回答。

随后粘贴 `01-Materials/L001-学校见面.md`。教案由家长查看，不交给孩子阅读。

## 第一遍

只告诉孩子场景是学校见面，播放官方音频。

问：“这两个人大概在做什么？”

原样记录回答，不立刻要求用完整英文回答。

## 第二遍

让孩子留意班级和老师信息，再次播放同一音频，依次提问材料卡中的两个细节问题。

记录实际答法、是否重播和提示，不能把第二遍的结果回填成第一遍成绩。

## 解决一个卡点

选择一个实际出现的问题。让孩子说当时理解成什么，再看相关原句并回听。

对照意思、人物关系、词语或声音，只处理当前证据支持的差异。看稿也不理解就先补词义；没有证据不要直接归因连读。

## 遮稿重听

收起原文，再播原音频。请孩子说出有关信息。记录“本次复听”，而不是写“已永久掌握”。

## 新情境

家长朗读L001卡中的自编新情境，或提前制作核对过的音频。提两个相近问题，看看她是否按新内容回答。

家长朗读与官方录音的条件不同，应记录；不要直接将两者结果当成同条件测量。

## 收尾

把真实记录交给ChatGPT，输入“今日复盘”。核对有没有把未做的环节补成已完成，删除任何缺乏依据的评语。

在本地private目录保存记录，按真实需要建最多2张卡，并把复习日放入私有队列。不要修改并提交公开模板。

如果第一次时间已到，就把新情境留到下一次。流程用于学习，不要求赶完所有环节。
