# 第一周试运行：嵌入原有课程

沿用仓库已有节奏，不额外增加每日课程；按实际可用时间顺延，不预设日历日期。

| 现有时段 | 系统任务 | 记录重点 |
| --- | --- | --- |
| 第一次Think主训练（约10—15分钟） | 用当日Think短片段运行先听、定位、对照、遮稿复听；也可用L001做一次流程演示 | 首次理解与辅助后理解分开 |
| 两次主训练之间的短时段 | 有余量时复习最多1—2张到期卡，不强制新材料 | 是否需要文字或提示 |
| 第二次Think主训练（约10—15分钟） | 继续同一主题或做一个未听过的短片段；不为换材料而换材料 | 新片段与旧答案分开 |
| 周末原有复盘（约5—10分钟） | 完成一个新情境检查和简短周回顾 | 下周只调整一项 |
| 学校／新概念既有时段 | 有实际需要时复用同一材料卡和记录方式 | 不重复加量 |

L002自编稿是可选补充，不是本周必做第二课。L003预留给实际学校或Think片段，具体学校版本、教材页码和音轨没有提供时不预填。Think已确定的主线地位不代表AI已取得当日原文与录音。

第一次使用本系统的目标是完成一遍“材料—训练—记录—卡片—回访”，不承诺达到某个等级。复习按实际首次练习日后的第1、3、7、14天初始安排，遇作业或休息冲突可顺延。

自编内容主要用于改变信息后的理解检查，不要求每天生成新长文。所有真实记录保存在本地private目录。
