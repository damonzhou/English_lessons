# 英语听力系统 · 家长管理版 v0.1.1（仓库集成版）

这是一套可在 Obsidian 中打开的 Markdown 模板与示范教案，不是已安装的软件服务。

## 先做这三件事

1. 将仓库下载或克隆到本地，在 Obsidian 中选择“打开文件夹为仓库”，打开 `English_lessons/03_listening/system`。也可作为普通Markdown文件夹使用。
2. 在家长的 ChatGPT 中创建专用项目“女儿英语听力”，把 `00-System/PROJECT_PROMPT.md` 中的指令正文放进项目指令。备课时提供当天材料卡；开练前提供当天材料与上次记录。不必上传全部档案。
3. 打开 `01-Materials/L001-学校见面.md`，由家长在官方页面播放音频，按 `06-Start/FIRST_SESSION.md` 进行第一次练习。

## 系统只围绕这一条流程

固定音频 → 不看稿听意思 → 记录当时的理解 → 对照原文解决一两个卡点 → 遮稿再听 → 隔日复习 → 换句子验证。

口语是辅助环节，不用英语表达的难度代替听力理解的难度。

## 课程衔接与起始背景

本模板面向家长管理的七年级学习场景，口语约A1、阅读约A2但基础需巩固的背景仅用于设计提示，不推断听力等级，不再单独定级。

保留仓库既有学校教材优先、Think Level 1长期听说主线、新概念补充的路线。L001、L002是演示/可选补充，不是新增主教材，也不取代正在学习的Think音频。

不在既有每日学习时间之外强制增加20分钟。20分钟是可拆分的完整流程；沿用Think每周两次主训练与一次复盘，普通日可仅复习一张卡或练一个卡点。

公开仓库只存模板。先阅读[私有数据说明](PRIVATE_DATA.md)，把填过的记录和复习队列放到本地`private/`，不要覆盖并提交公开模板。

## 已经包含什么

- 固定训练协议、选材规则、完整ChatGPT项目指令。
- 官方材料第一课、自编材料第二课与新情境练习。
- 每日记录、听力卡、人工维护的复习队列、每周回顾模板。
- 第一周安排，以及不用插件的本地音频区间播放器。

## 尚未发生什么

- 仓库文件交付不等于设备安装；未创建或修改你的ChatGPT项目、本地Obsidian配置。
- 未读取女儿的实际答题或录音；所有记录都是空模板，没有虚构的成绩。
- 包内没有MP3文件。第一课提供官方网页音频入口；自编课文只有脚本，需家长朗读或制作并核对音频。
- 未设置定时提醒；复习日期由家长按实际开练日期填写。
- ChatGPT与本地Obsidian之间没有在本包中建立自动同步。复盘先由家长核对，再复制保存。
- 原X帖只核实到搜索可见片段，完整步骤及附件未获取。本包是基于已核实思路的独立实现，不是原帖完整复刻，详见 `SOURCE_MAP.md`。

## 日常分工

女儿：听、作答、说明卡点、必要时跟读与简短回应。

家长：选材料、控制文字何时出现、保存原始回答、核对复盘、安排复习。

ChatGPT：备课、就已有证据讲解、生成新情境练习、整理复盘。

Obsidian：长期保存材料、真实记录、听力卡和复习队列。
