# 固定训练协议 v0.1.1

## 目标与边界

目标是把一次听力中的困难转化为后续可以复习、可以验证的具体项目，而不是积累收听时长。

不另做听力定级。不因为阅读或口语等级替孩子指定听力等级。用实际练习中的支持需求调节下一份材料，不用一次练习给孩子下结论。

## 与仓库课程衔接

本协议是既有课程的训练执行层，不新增并行教材。保留学校教材优先、Think Level 1长期听说主线、新概念补充。示例L001/L002可替换为当日已经安排的学校或Think片段；保留实际来源、版本和题目依据。

沿用Think每周两次主训练与一次复盘。下面20分钟为完整流程的参考上限式安排，不要求每天额外完成；10—15分钟主训练可拆分，新情境也可留到复盘。普通日按既有5—8分钟听力时段做局部练习。

## 一次20分钟的参考流程

| 环节 | 参考时长 | 家长或系统做什么 | 孩子做什么 |
| --- | --- | --- | --- |
| 旧卡复习 | 2分钟 | 播放最多2张到期卡；不显示答案 | 听后说意思，可用中文 |
| 新材料整体听 | 2分钟 | 只给场景；隐藏原文；保留第一遍回答 | 听后回答一个大意问题 |
| 再听与定位 | 3分钟 | 问2个细节；重播同一音频，不改词 | 说出理解与不确定之处 |
| 对照解决卡点 | 5分钟 | 展示原文；只选1—2个重点 | 对照自己原来的理解，再听目标句 |
| 遮稿复听 | 3分钟 | 隐藏文本，恢复原音频原速 | 不看稿说明意思与关键细节 |
| 换情境 | 3分钟 | 用熟悉词汇换1—2项信息 | 再听后回答，不强求长句 |
| 复盘 | 2分钟 | 核对记录；最多新增2张卡 | 说出今天解决了什么 |

时长仅是起始配置；作业繁忙可拆成两天，不用补偿性加倍。当天只有10分钟时，保留整体听、一个卡点与遮稿复听，其余移到下次。

## 防止练习变成阅读或背答案

首次播放前不显示原文、译文与答案。练习前已看过稿，必须记录“已看稿”，不记作未见稿首听。

音频中的含义理解可以用中文、选择、指认或排序来回答。英语语法错误单独记录，不能自动折算成听力错误；拼写错误也不自动证明没听到。

同一段音频的重播使用同一版本，不让AI临时改写。训练后能答对原句，记为“本次复听理解”，不直接等于长期掌握。

## 每个卡点的处理链

保存当时的理解 → 对照原句 → 确认差异 → 提供最小解释 → 遮稿重听 → 用新句检查。

可选工作标签：

- SOUND：看文字认识，但在本段语音里没认出；具体发音原因待音频证据确认。
- WORD：本次遇到未知词义或搭配。
- STRUCTURE：词基本认识，但人物、动作、否定、时间等关系理解有误。
- DETAIL：主要意思抓到了，但关键信息未保留；不能直接推断成记忆能力不足。
- UNCERTAIN：题目、转写、音频或孩子表达存在歧义，尚不能分类。

标签描述这一处表现，不是孩子能力标签。证据不足用UNCERTAIN。

## 声音训练与基础知识

只讲这段材料中确有需要的一个词义、一个搭配或一个句子关系。回到正在学的课本知识说明，不一次展开整章语法。

分句听后跟读仅用于帮助核对声音与文字。第一阶段不强制整段影子跟读、全文默写、母语口音模仿或不懂也反复听几十遍。

## 材料与音频证据

有原始音频和人工/官方文字稿时，以二者核对后的版本为准。有文字稿但未听取音频，AI只能提供一般语音提示，不能声称该录音一定发生某种弱读、吞音或连读。

AI只看到转写时，不能凭转写判断发音。家长应保留孩子原来的表达，不让AI先润色再当成原始记录。

## 复习与调整

在实际首次练习日之后的第1、3、7、14天回访，日程可调整。这是实施安排，不宣称是“遗忘曲线最优时间”。

原句保留与新情境理解分开。第7或14天至少一次改时间、地点、人物或活动，避免只凭记住的答案。

一项在独立听取时未完成，就安排下一个练习日再查，并保留失败记录。不因此把所有内容清零或增加新卡。

连续几次同类材料都只需很少帮助时，一次只调整一个变量：长度、信息点数量、句式复杂度或说话者。不能同一天同时加长、加速、增加生词。

## 家长与AI的边界

家长负责实际与AI交互、材料审查和资料保存。孩子不需要提供真实全名、学校、住址等个人信息。公开仓库只保存模板，真实记录和音频保存在本地private目录，见[私有数据说明](../PRIVATE_DATA.md)。

未读到真实训练记录时，不报告进步、不打CEFR分数、不编造连续学习天数。每周回顾只看已记录证据。
