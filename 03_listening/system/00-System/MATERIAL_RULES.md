# 选材与入库规则

## 起始配置

| 项目 | v0.1.1配置 |
| --- | --- |
| 场景 | 每次一个：学校、朋友、家庭、兴趣等 |
| 长度 | 参考30—60秒；自编稿约40—80词；不以词数推断真实时长 |
| 新内容 | 最多3个必要新词、1个需要讲明白的句子结构、2个常用表达 |
| 每周新增 | 沿用现有Think两次主训练与一次复盘；可重复同一片段，不强制新增三份 |
| 来源 | 学校教材优先；Think Level 1为长期听说主线；新概念补充；官方示例和自编内容用于演示或迁移 |
| 呈现 | 自然清晰，不刻意拆成逐词报读；先隐藏原文 |

这些参数是实施起点，不是根据口语或阅读给孩子判定听力等级。

## 每份材料必须有

材料ID、标题、来源链接或教材位置、音频版本/文件名、原文来源、实际使用范围、一个大意任务、两个细节任务、答案、最多两个学习重点。

原稿、改写稿与不同声音录制版分别编号。新句和旧句不能混进同一个“掌握率”。

## 没听懂时先修改任务，不立刻升级材料

阅读稿也很难理解时，先缩短并补必要词义。阅读能懂但声音没对上时，截取相关一句，回到同一录音。内容理解正确但英文答不出时，允许中文或选项，另外处理口语。

这些是按当前练习证据作出的教学调整，不是先验诊断。

## 不把兴趣输入全变成考题

另可保留不计分的故事或兴趣音频，孩子不需要逐句整理。但它和本系统的重点训练分开记录，不把播放时长当掌握证据。
