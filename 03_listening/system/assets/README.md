# 音频文件目录

本包未附带音频文件。第一课可以直接在官方页面播放。

优先把有权使用的音频放在本地`private/assets/`，并记录真实文件名、版本与范围。此公开目录仅保留说明；即使个人拥有使用权，也不等于拥有公开分发权。不要上传无公开分发权的音频，不把未生成的文件写成“已存在”。

已有音频文件时，Obsidian可以用 `![[真实文件名.mp3]]` 嵌入。

需要区间复读时，可在桌面浏览器打开 `tools/audio-player.html`，选择本地音频，再设置A/B点。文件由浏览器本地读取；本工具没有上传逻辑、账户、联网代码或自动存档。

首次使用播放器需在自己的设备上检查音频加载、变速与区间复读。没有在你的设备上验证过其运行情况，手机文件预览器也不一定执行HTML脚本。
