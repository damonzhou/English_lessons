# 听力

训练目标：从“听到单词”逐步发展为“听懂句子、对话和主要信息”。

- [完整训练协议](system/00-System/PROTOCOL.md)与[ChatGPT项目指令](system/00-System/PROJECT_PROMPT.md)。

## 固定训练流程

固定音频 → 盲听大意 → 记录当时理解 → 再听细节 → 对照解决1—2个卡点 → 遮稿复听 → 间隔复习 → 新情境验证。

原有盲听、对照、再听、跟读继续保留。跟读用于核对声音、重音、节奏和停顿；原有“用2—5句复述”保留为可选口语延伸，不是听力通过条件，也不要求每次完成。

听力内容理解允许中文、选择、指认或简短英文作答。口语语法、拼写和长句复述能力另行记录，不据此判定没听懂。

## 与原有课程衔接

本系统是执行层，不新增并行教材，也不替换Think课程。Think日直接把当日音频放入材料卡；L001官方示例与L002自编稿只用于演示或补充。

沿用现有每周节奏：Think两次主训练、一次复盘，学校音频随校内进度，新概念按原计划补充。不在原有每日学习时间之外强制新增20分钟；协议中的20分钟为可拆分的完整流程，短练习可用5—10分钟完成其中一部分。

不单独进行听力定级，不从口语或阅读等级推断听力等级。材料标注的A1/A2属于来源标注。已有“听懂百分比”仅作家长粗略观察，不作为测级或硬性通关阈值。
