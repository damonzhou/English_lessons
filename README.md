# English Lessons

七年级英语长期学习与知识沉淀仓库。

## 目标

以学校教材为校内第一主线，以 Think Second Edition Level 1 作为长期听力和口语主线，结合《新概念英语》1/2、阅读与写作训练，形成可长期维护的英语学习体系。

核心原则：

- 学校教材优先，保证校内基础与考试要求。
- Think Level 1 负责长期 A2 听力、口语和主题化综合输入。
- 当前主动口语可低于教材等级，通过跟读、替换、提示式表达逐步过渡到 A2 输出。
- 新概念1/2用于句型、语法、精读、跟读和复述补强。
- 每日少量、高频、持续训练。
- 单词、听力、口语、阅读、写作相互联动。
- 强调“输入 → 积累 → 使用 → 纠错 → 再使用”。
- 错误反复出现时建立专项微课，而不是机械增加题量。

## 当前课程结构

1. **学校教材**：校内学习第一主线。
2. **Think Second Edition Level 1（A2）**：长期听力 + 口语主线。
3. **新概念英语 1 / 2**：句型、语法、精读、复述补充。
4. **阅读 / 写作材料**：按能力和学校需求动态选择。
5. **专项微课**：由真实重复错误触发。

## 日常使用方式

日常学习内容先进入对应模块。Think 日尽量把 Listening 和 Speaking 放在同一次训练中，形成：

**盲听 → 理解 → 对照 → 跟读 → 替换 → 提示式表达 → 原教材口语任务**

有价值的词块、句型和错误要沉淀到长期知识库。每周在 `10_reviews/` 做复盘，如同类错误连续出现 2–3 次，则在 `07_grammar/` 或对应能力模块建立专项训练文档。
