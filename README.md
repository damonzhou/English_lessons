# English Lessons

七年级英语长期学习与知识沉淀仓库。

## 目标

以学校教材为主线，结合《新概念英语》1/2、听力、口语、阅读和写作训练，形成可长期维护的英语学习体系。

核心原则：

- 学校教材优先，保证校内基础与考试要求。
- 每日少量、高频、持续训练。
- 单词、听力、口语、阅读、写作相互联动。
- 强调“输入 → 积累 → 使用 → 纠错 → 再使用”。
- 错误反复出现时建立专项微课，而不是机械增加题量。

## 目录

- `00_plan/`：全年、月度、每周、每日学习计划与打卡规则
- `01_school_textbook/`：学校教材单元笔记、课文、核心词汇与校内重点
- `02_vocabulary/`：词汇、词块、搭配与主题词汇积累
- `03_listening/`：听力训练方法、材料记录与精听笔记
- `04_speaking/`：跟读、替换表达、提示式表达与自由表达训练
- `05_reading/`：阅读理解方法、精读记录、题型与错因分析
- `06_writing/`：写作方法、主题素材、句型库与作文修改记录
- `07_grammar/`：语法知识点、易错点与专项微课
- `08_new_concept/`：新概念英语 1/2 的选择性学习与迁移记录
- `09_error_log/`：真实作业、考试和训练中的错误追踪
- `10_reviews/`：周复盘、月度复盘、阶段能力评估
- `resources/`：素材来源、教材说明、参考材料索引

## 使用方式

日常学习内容先进入对应模块；有价值的词块、句型和错误要沉淀到长期知识库。每周在 `10_reviews/` 做复盘，如同类错误连续出现 2–3 次，则在 `07_grammar/` 或对应能力模块建立专项训练文档。
