# 七年级英语写作训练计划

## 1. 目标

七年级阶段完成从“会写几个正确句子”向“能够围绕熟悉主题写出连贯短文”的过渡。

重点不是追求复杂句，而是建立以下能力：
- 看懂题目并明确写作目的；
- 能迅速列出 3–5 个内容要点；
- 用正确、自然的简单句表达；
- 用 and / but / because / so / first / then / after that 等形成基本连贯；
- 从学校教材、Think、阅读和新概念中主动调用词块和句型；
- 写完能够检查、修改和重写；
- 修改后的文章可以转成口语复述。

## 2. 教材分工

### 学校教材 / 学校作文
优先级最高。

负责：
- 校内常考题型；
- 老师要求的格式和字数；
- 考试评分习惯；
- 真实作业与考试错误样本。

### Think Second Edition Level 1 Writing
长期能力主线。

Think Level 1 的 12 个 Writing 任务覆盖 routine、email、food、invitation、blog/summary、thank-you note、housework、sporting event、weather event、informal email、phone message、someone I admire 等类型。

用途：
- 学习文章结构和写作目的；
- 从同主题 Reading / Listening / Speaking 获取语言输入；
- 学习不同短文体裁；
- 将本周听说表达迁移到写作。

### 阅读 / 新概念
不单独承担作文课程，但负责提供：
- 高频词块；
- 可迁移句型；
- 内容素材；
- 表达方式。

## 3. 每周执行节奏

通常每周安排 1 次正式写作，另加少量改写或句子训练。

推荐节奏：

### 周一到周四：输入与积累
从学校、Think、阅读或新概念中累计：
- 2–3 个本周主动词块；
- 1–2 个可迁移句型；
- 一个主题内容点。

### 周五：正式写作
从以下来源选一个题：
1. 学校真实作文；
2. 当前 Think Unit 原 Writing；
3. `writing_bank.md` 的同主题扩展题。

### 周六：修改
完成：
- 错误检查；
- 内容补充；
- 句子连接；
- 至少修改 1–3 处；
- 条件允许时形成终稿。

### 周日或下周：口头迁移
不看全文，根据关键词把文章内容说出来。

## 4. 固定七步写作流程

### Step 1 — Input
先看 Think / 学校提供的范例或同主题输入。

只分析：
- 写作目的；
- 文章包含哪些信息；
- 内容顺序；
- 连接方式。

不背整篇范文。

### Step 2 — Collect
从本周输入中挑选 2–5 个值得主动使用的表达。

例如：
- in my free time
- spend time doing sth.
- be interested in
- first / then / after that
- because / but / so

### Step 3 — Plan
写之前先列要点。

一般只需要回答 3–5 个问题，例如：
- Who / What?
- When?
- Where?
- Who with?
- Why / How did you feel?

### Step 4 — Draft
先完成第一稿。

前期要求：
- 60–80 词为主；
- 允许以正确简单句为主体；
- 不为了高级表达故意写不会控制的复杂句。

### Step 5 — Check
固定检查：
- [ ] 内容是否回答题目要求
- [ ] 大小写和标点
- [ ] 主谓一致
- [ ] 单复数
- [ ] 时态
- [ ] 拼写
- [ ] 连接词是否自然

### Step 6 — Rewrite
根据检查和反馈形成修改稿。

重点修改：
- 漏掉的内容；
- 明显重复；
- 不自然的中文式表达；
- 可用本周积累替换的普通表达。

### Step 7 — Speak
适合的作文在修改后，用关键词复述一次。

目的：让写作表达进入主动口语，而不是只停留在纸面。

## 5. 字数与难度升级

### 阶段 A：A1+ → A2 起步
- 50–70 词；
- 3–5 个内容点；
- 正确简单句；
- and / but / because 等基础连接。

### 阶段 B：稳定 A2
- 60–80 词；
- 有清楚开头和内容顺序；
- 能写简单邮件、段落、邀请、短文；
- 主动调用 2–3 个积累表达。

### 阶段 C：A2 → B1 过渡
- 80–100 词；
- 内容更完整；
- 能加入原因、感受、经历和简单观点；
- 减少模板依赖。

升级按实际能力，不按月份自动发生。

## 6. 题库使用规则

`writing_bank.md` 每个 Think Unit 提供 3 个层级：

- **A 仿写**：题目结构接近 Think 原任务，提示充分；
- **B 迁移**：同能力换场景，提示减少；
- **C 独立**：在同主题上增加个人选择、原因或观点。

一个 Unit 不要求三个题全部写。

通常：
- 初次学习选 A；
- 能力稳定后选 B；
- 需要检验真正迁移能力时选 C。

## 7. 范文使用规则

范文有三个用途：
1. 看结构；
2. 找可迁移表达；
3. 与自己的文章比较后修改。

正确顺序：

**先自己规划 / 写 → 再看范文 → 比较 → 修改。**

避免：
- 先背范文再套写；
- 为了“高级”积累大量当前不会使用的句型；
- 把不同主题的范文整体背诵。

`model_answer_bank.md` 提供原创 A2 标准范文。Think 原书范文只在使用正版教材时阅读，不复制到仓库。

## 8. 每篇作文评价维度

每次不需要打复杂总分，但至少记录五项：

| 维度 | 观察点 |
|---|---|
| Content | 是否回答完整，信息是否足够 |
| Organisation | 顺序是否清楚，连接是否自然 |
| Accuracy | 时态、主谓、单复数、拼写 |
| Language | 词汇句型是否适合，是否有明显中式表达 |
| Transfer | 是否主动使用近期积累表达 |

## 9. 错误触发规则

- 偶然错误：当篇订正；
- 同类错误第 2 次出现：加入写作检查清单；
- 同类错误连续 2–3 次：转入 `07_grammar/` 或对应专项微课；
- 内容总是写不出来：先训练 Plan，不增加范文背诵；
- 句子单一但正确：增加连接和句型替换；
- 复杂句错误很多：主动降回可控表达。

## 10. 每 4 周复盘

检查：
- 完成了多少篇有效写作；
- 第一稿与终稿差异；
- 最常见 3 类错误；
- 新积累表达实际调用率；
- 是否仍高度依赖中文翻译；
- 是否能把修改后的文章口头复述；
- 是否需要调整字数或题目层级。

目标不是累计篇数，而是让后一篇明显优于前一篇。
