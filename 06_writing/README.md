# 写作

七年级写作目标：不靠临考背范文，而是建立一套可持续的 **输入 → 积累 → 规划 → 写作 → 修改 → 再表达** 系统。

## 当前教材定位

1. **学校教材 / 学校作文题**：校内第一优先级，保证题型、字数和考试要求。
2. **Think Second Edition Level 1 Writing**：长期写作能力主线，与听力、口语主题联动。
3. **阅读 / 新概念英语 1/2**：提供词块、句型和内容素材。
4. **扩展题库**：围绕 Think Level 1 的 12 个核心写作任务扩展为全年约 36 个候选题。

Think Level 1 负责“教会怎么写”，扩展题库负责“提供足够练习量”。不额外并行一整套写作教材。

## 目录

- `writing_plan.md`：全年写作训练计划、执行流程、评价与升级标准
- `writing_bank.md`：Think Level 1 12 个 Unit 对应的 36 题分级题库
- `model_answer_bank.md`：每个主题的原创 A2 标准范文与升级方向
- 后续可增加：
  - `school_prompts/`：学校真实作文题
  - `essays/`：学生原稿、修改稿、终稿
  - `sentence_bank/`：可迁移词块和句型

## 核心原则

- 每周通常完成 1 次正式写作或一次有效改写。
- 前期以 60–80 词为主；稳定后逐步进入 80–100 词。
- 先追求内容完整、句子正确和基本连贯，再增加复杂度。
- 范文用于分析和比较，不用于机械背诵。
- 每篇至少尝试主动使用 2 个近期积累表达。
- 写完必须修改；“第一稿”不是最终成果。
- 适合的文章在修改后再口头复述一次，让写作反哺口语。
